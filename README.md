# 好康复 · 术后康复语音带练

按北医三院运动医学科发给患者的术后康复计划，每天自动排好要做的练习，语音带着你做，做完自动记下来。目前有两份计划：

- 膝关节 · 前交叉韧带重建
- 踝关节 · 外踝韧带止点重建

## 安卓手机：用 App（推荐）

下载：https://haokangfu.github.io/app

到点提醒；锁屏、切到别的 App 都不停；带练语音还能和别的 App 的声音一起放。

## iPhone：暂时先用网页版

网页版：https://haokangfu.github.io

iPhone 暂时没有 App，可以先用网页版代替，功能比 App 少一些：没有到点提醒，别的 App 一出声音，带练语音会停。用 Safari 打开，点「分享」→「添加到主屏幕」，以后从桌面图标打开，没网也能用。鸿蒙 NEXT 手机装不了安卓安装包，也可以先用网页版。

不用注册，记录只存在你自己的手机里。

> 个人制作，不是医院官方出品；康复怎么做，以医生和康复师的嘱咐为准。
